## 🌟 Key Features

- **Atkinson 1-Bit Dithering Pipeline:** Real-time monochrome error diffusion image processing optimized for retro e-ink and CRT terminals.
- **Telegram Promo Bridge:** Bidirectional thread synchronization between 2ch/4chan boards and Telegram channels.
- **Circular Buffer Thread Cache:** High-concurrency SQLite WAL storage with automatic purge and zero media loss.
- **Live Terminal Web Showcase:** Interactive web client with retro terminal HUD and live preview.
